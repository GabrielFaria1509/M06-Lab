# 📚 Cálculo Numérico e Estatística

Repositório destinado ao armazenamento dos exercícios desenvolvidos durante as disciplinas de **Cálculo Numérico** e **Estatística**.

Os exercícios são implementados em **Python**, utilizando principalmente **Jupyter Notebooks (`.ipynb`)**, reunindo resoluções, estudos e aplicações dos conteúdos vistos em aula.

## 🛠️ Tecnologias Utilizadas

* Python 3
* Jupyter Notebook (`.ipynb`)
* NumPy
* Matplotlib
* SciPy *(quando necessário)*

## 📂 Conteúdo

O repositório será atualizado ao longo da disciplina com exercícios envolvendo temas como:

* Métodos de aproximação numérica
* Resolução de equações
* Sistemas lineares
* Interpolação
* Integração e derivação numérica
* Estatística descritiva
* Probabilidade
* Distribuições estatísticas
* Outros exercícios propostos em aula

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

2. Instale as dependências necessárias:

```bash
pip install numpy matplotlib scipy notebook
```

3. Inicie o Jupyter Notebook:

```bash
jupyter notebook
```

4. Abra o notebook (`.ipynb`) desejado e execute as células.
